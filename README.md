# ai601-data-engineering

## Project Overview
This project focuses on building a data pipeline using Python, where students collect and clean weather data from an API, store it in a CSV file, and perform basic data cleaning operations. The project utilizes the requests library to make HTTP requests and interact with web data. The goal is to design a functional data pipeline that can fetch, clean, and summarize weather data, providing a hands-on experience with data collection and cleaning concepts.
